# Memory Root — Overview (L1)

This directory is the context root for all agents in `agent-memory-lab`. The tree follows a three-tier model:

- **L0** (`.abstract.md`): ≤256 chars, always injected. Describes the directory.
- **L1** (`.overview.md`): ≤4,000 chars, loaded on demand. Index of contents.
- **L2** (all other `.md` files): unlimited, pulled explicitly.

## Subdirectories

| Dir | L0 Summary | Contents |
|-----|-----------|----------|
| `entities/` | People, orgs, and projects | One file per entity, slug-named |
| `events/` | Decisions and milestones | YYYY-MM-DD-slug.md |
| `preferences/` | User and agent preferences | Topic-organized |
| `skills/` | Reusable execution patterns | One file per skill |
| `sessions/` | Per-session summaries | YYYY-MM-DD-HH-slug.md |

## How to write new memory

1. Pick the right subdirectory.
2. Create a file with a descriptive slug name.
3. Update this file (`memory/.overview.md`) with a one-line entry in the relevant subdirectory row.
4. If the root `.abstract.md` is stale, update it (keep ≤256 chars).
